Free online SQL editor

  
SQL Playground lets you write and run SQL in your browser without installing a database. Pick a dialect, load a sample database or your own file, and see results in a table you can sort, filter and copy. Everything runs on your device, so your data never leaves it.


  
How to run SQL online

  
    
    
  1. Choose a dialect from the menu at the top: SQLite, MySQL / MariaDB, PostgreSQL, SQL Server (T-SQL), Oracle, MaxCompute (ODPS) or Hive / Spark SQL.
    2. 
    
  2. Load data. Open the ⋯ menu and pick a sample database, or import a CSV, TSV, JSON, SQL or SQLite file.
    3. 
    
  3. Write a query in the editor, or start from the Examples tab. Autocomplete suggests tables and columns as you type.
    4. 
    
  4. Press Run (Ctrl/⌘ + Enter). To run only one statement, place the cursor in it and press Shift + Ctrl/⌘ + Enter.
    5. 
    
  5. Use the results. Filter rows, sort columns, then copy them as TSV for Google Sheets or Excel, or as CSV, Markdown, JSON or INSERT statements.
    6.

Frequently asked questions

  
Do I need to install MySQL or PostgreSQL?
No. The playground uses SQLite built into the page and translates the dialect you pick, so most everyday queries run as written.

  
Why does a query work here but not on my real database?
Some vendor-only features, such as stored procedures or special data types, can't be translated. Test those on the real server before you rely on them.

  
Can I use my own spreadsheet?
Yes. Save it as CSV and import it from the ⋯ menu. Each file becomes a table you can query right away.

  
Is it good for SQL interviews and exams?
Yes. The sample databases cover the usual topics: joins, GROUP BY, subqueries, CTEs and window functions.

  
Does it work on a phone?
Yes, but it's easier on a computer, where the editor and the results fit side by side.
