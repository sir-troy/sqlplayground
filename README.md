# SQL Playground

Write and run SQL right in your browser.

**Live:** https://sqlplayground.useful-indeed.com

SQL Playground is a full SQL workspace that runs entirely in your browser. Write queries in SQLite, MySQL / MariaDB, PostgreSQL, SQL Server (T-SQL), Oracle, MaxCompute or Hive / Spark SQL — the playground translates them so they run on a built-in SQLite engine. Practise with ready-made sample databases, import your own CSV, JSON, SQL or SQLite files, and copy results straight into a spreadsheet. There's nothing to install and no server to connect to.

## How to use

1. Pick a SQL dialect at the top.
2. Load a sample database from the ⋯ menu (support desk, e-commerce or company HR), or import your own file.
3. Write a query — or start from the Examples tab — and press Run (Ctrl/⌘ + Enter).
4. Filter the results and copy them as TSV, CSV, Markdown, JSON or INSERT statements.

## Privacy

Everything runs in your browser. Your query tabs, history, theme and current database are saved in your browser's local storage so you can pick up where you left off. Imported files are read on your device and never uploaded.
